LAFAYETTE VARSITY SOCCER WEBSITE CONCEPT

Contents:
- index.html: responsive one-page website prototype
- assets/: your supplied team, match, logo, and jersey images

How to preview:
1. Extract the ZIP folder.
2. For the interactive 3D jersey module, open the folder through a local web server or upload it to a static website host. The page loads Three.js from a CDN, so internet access is required.
3. Keep the assets folder next to index.html.

Important:
- This is a fan-made concept, not an official school website.
- Historical records should be verified specifically for Lafayette High School in Buffalo, NY; similarly named Lafayette soccer programs in other states have different histories.
- Confirm team photo permissions and school/brand permissions before public launch.
- Match entries are starter examples and should be confirmed against the team's official records.
